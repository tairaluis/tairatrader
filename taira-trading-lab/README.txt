# Taira Trading Lab — landing page

Página estática responsiva para publicar no GitHub Pages ou Netlify.

## Arquivos
- `index.html`: página principal.
- `assets/luistaira-retrato.png`: retrato enviado pelo proprietário.

## Oferta apresentada
- Uma assinatura única de R$ 47 por mês.
- 7 dias de garantia.
- Cancelamento quando quiser, sem fidelidade.
- Sala BTC, cursos e ferramentas apresentados como parte do ecossistema da assinatura.

## Publicação no Netlify
1. Extraia o ZIP.
2. Entre no Netlify e arraste a pasta extraída para a área de deploy manual.

## Publicação via GitHub
1. Envie `index.html` e a pasta `assets/` para o repositório.
2. No Netlify, importe o repositório. Não é necessário comando de build; diretório de publicação: `.`.

## Antes de divulgar
- Confirme que todos os itens listados estarão realmente incluídos na assinatura.
- Adicione o link real de checkout de R$ 47/mês aos botões de assinatura.
- O botão da Sala BTC aponta para https://luistaira.com/sala-btc/.
- Confirme os termos da garantia de 7 dias e o procedimento de cancelamento conforme as regras da plataforma de pagamento.
